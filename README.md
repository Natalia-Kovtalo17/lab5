# Лабораторна робота № 5: кешуючий проксі-сервер

Простий кешуючий проксі-сервер на Node.js (модуль `http`). Картинки з https://http.cat зберігаються в кеші на диску й віддаються звідти під час повторних запитів.

## Встановлення

```bash
npm install
```

## Запуск

```bash
npm start -- -h 127.0.0.1 -p 3000 -c cache
```

Опції (усі обов'язкові):

| Опція | Призначення |
|---|---|
| `-h, --host` | адреса сервера |
| `-p, --port` | порт сервера |
| `-c, --cache` | тека для кешу (створюється автоматично) |

## Методи

| Метод | Дія | Успішна відповідь |
|---|---|---|
| GET `/<код>` | повертає картинку з кешу або з http.cat | 200, `Content-Type: image/jpeg`, заголовок `X-Cache: HIT` або `MISS` |
| PUT `/<код>` | записує картинку з тіла запиту в кеш | 201 |
| DELETE `/<код>` | видаляє картинку з кешу | 200 |
| інші | | 405, заголовок `Allow` |

Якщо картинки немає ні в кеші, ні на http.cat, сервер відповідає 404.
